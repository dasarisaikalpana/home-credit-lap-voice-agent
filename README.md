# Home Credit – Loan Against Property (LAP) Eligibility Voice Agent

## Project Overview
An AI-powered voice agent built using Retell AI to assess existing Home Credit customers' eligibility for a Loan Against Property (LAP) offer of up to ₹75 lakh.

## Objectives
- Verify customer identity and availability.
- Identify existing property-loan transfer or EMI-reduction requests.
- Evaluate customers against seven LAP eligibility criteria.
- Route eligible customers to a senior loan expert.
- Politely conclude calls when customers are ineligible.

## Eligibility Criteria
1. **Property Type:** Residential, commercial, or industrial. Agricultural property is ineligible.
2. **Ownership:** Sole or joint ownership is accepted.
3. **Property Documents:** Original documents must be available for verification.
4. **Loan Amount:** Maximum ₹75 lakh.
5. **Occupation and Income:** Salaried or self-employed; income must be received through a bank.
6. **Property Market Value:** Capture the customer's estimated market value.
7. **Tenure:** Between 3 and 15 years, inclusive.

## Call Routing
- Existing property loan or EMI-reduction/transfer request → Loan-transfer specialist.
- Meets all seven eligibility criteria → Senior loan expert.
- Fails a mandatory criterion → Explain politely and end the call.
- Customer is busy → Ask for a suitable callback time and end the call.

## Technology
- Retell AI
- AI voice agent and prompt engineering
- Conversational AI and call routing

## Testing
Test the agent with eligible and ineligible customers, joint ownership, unavailable documents, cash income, agricultural property, loan amounts above ₹75 lakh, existing-loan transfers, and callback requests.
